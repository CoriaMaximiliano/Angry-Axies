Angry Axies for Android (APK)

The official download for the current build is on GitHub, in release 1.126. Open the release page and download the APK from Assets.

Direct download for this version (1.126):

AngryAxies-1.126.apk

You can also use the latest published release: releases/latest

Requirements

  • Android 6.0 or higher
  • Landscape orientation recommended
  • Internet connection for leaderboard and PvP

Install on your phone

  1. Download AngryAxies-1.126.apk on your phone (Chrome, Drive, USB, etc.).
  2. Open the downloaded file. If Android asks for permission, enable “Install unknown apps” only for that browser or file manager.
  3. Confirm installation. The icon will appear as Angry Axies.
  4. When you open the app, tap the screen once if audio does not start (Android requirement).

The app bundles the same game as the browser and connects to angryaxies.servehttp.com for leaderboard, health, and PvP.

Play without installing: use the web version at angryaxies.servehttp.com (best on PC; also works in mobile browsers).

Updates (for publishers): when you build a new APK with npm run android:apk, rename it to AngryAxies-X.XXX.apk, create a GitHub release with that tag, and update the links on this page.

Security note: this is a debug build. Android may warn about apps from unknown sources; install only if you trust the project.
